# 模板 B：信息推送（只推和持仓对得上的）

**何时用**：`news.py` / `monitor.py` 产出的条目；用户问“XX 为什么涨跌”。
**四道闸**（全部通过才推）：
1. **关联**：能匹配到某只持仓（代码、公司名、别名）。公告按“发行人”抓取，天然属于该持仓。对不上的丢弃。v0.1 只做**直接关联**，板块、宏观等间接关联默认不推。
2. **新鲜**：实时推送只推 60 分钟内的新闻；公告只有日期的，限当日或前一日。日报可放 24 小时内的。
3. **重要**：高（实时推）：财报/指引、并购重组、回购分红拆股增发、诉讼调查监管处罚、停牌退市、高管变动、评级调整、召回、重大合同。中（只进日报）：产品发布、合作、行业数据。低（丢弃）：观点评论、榜单、“值得买的 X 只股票”。
4. **去重**：同一事件多家报道合并为一条，保留最权威或最早的来源，注明“另有 N 家媒体报道”；同一标的实时推送每天最多 3 条。

```
📰 NVDA 英伟达｜仓位32% · 今日🔴+7.3% · 浮盈+21.6%
【新闻·高】Nvidia faces SEC investigation
关联：直接涉及你持有的 NVDA
来源：Reuters · 11-10 20:30｜另有 12 家媒体报道
```

**Muse 的工作**：每个条目带 `needs_summary=true`，用**自己的话**补一句话概括（不要照抄原文，不确定就不写）；排版按渠道调整。
公告类写“当日披露”，不写具体小时。查不到消息就不要发，也不要猜。
