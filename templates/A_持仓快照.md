# 模板 A：持仓快照

**何时用**：用户问“我的持仓 / 总金额 / 今天赚了多少”，或配置了定时快照。
**生成**：`python3 scripts/snapshot.py`（文本草稿）；`--json` 取完整数据。
**内容顺序**固定，排版由 Muse 按当前渠道调整（微信用纯文本、少量 emoji；邮件可更完整）。

```
📊 我的持仓 · 11-10 21:35（北京）
总金额 ¥1,286,400
今日 +¥8,320（+0.65%）
累计浮盈 +¥156,200（+13.8%）

```

**规则**
- 按折算市值降序；每个市场标当前时段。
- 某只缺行情：写“暂无行情”和原因，不留空、不编数据；总金额注明“部分标的缺数据，未计入”。
- 缺汇率：总金额不折算，并注明。
- 涨跌图标按 `color_scheme`：默认红涨绿跌。
- 数据行必须有：本市场时间（和用户本地时间）、来源、状态（实时 / N 分钟前 / 收盘 / 夜盘参考价 / 今日可能休市）。
