# 模板 D：日报

**何时用**：定时任务（见 cron/CRON.md）。**生成**：`report.py --market US|CN|HK|ALL --kind pre|post|close`。
疑似休市（当日没有成交数据）时脚本输出 `NOOP`，不发空日报。

```
📋 美股盘后日报 · 11-10 21:35（北京）

【账户总览】
总金额 ¥1,286,400
今日 +¥8,320（+0.65%）
累计浮盈 +¥156,200（+13.8%）
汇率 USD→CNY 7.2000｜HKD→CNY 0.9200（Yahoo · 06:45 UTC）

【美股持仓明细】按市值排序（盘后）
NVDA 英伟达 $182.35 🔴+7.26%
 100股 · 成本$150.00 · 浮盈+21.6% · 仓位32%
…

【重点异动】
• NVDA +7.3%：Nvidia faces SEC investigation（Reuters）

【持仓相关消息】
• NVDA｜Nvidia unveils new chip（Yahoo · 11-10 18:20）[中]

【数据说明】
数据：美股 16:42 ET（北京 05:42） · Nasdaq · 实时
⚠ …（缺数据、休市、两源价差等）
以上仅为信息整理，不构成投资建议。
```

**规则**
- 重点异动：涨跌幅不小于 2% 的持仓里，按对账户影响金额取前 3 条，各配一句话原因，查不到写“暂未找到明确消息”。
- 持仓相关消息：过四道闸（见模板 B）后，高、中级别进日报，低级别丢弃。
- 数据说明必须列出来源、延迟、降级、两源价差和休市提示。
- 港股、A 股日报没有盘前盘后；美股盘前日报重点看隔夜消息和盘前价。
