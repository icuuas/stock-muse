# stock-push：让 Muse 替你盯美股、港股、A 股持仓

对 Muse 说一句话，它会在自己的云电脑里装好一套**持仓盯盘**工具：记录你的持仓、随时回复“我的持仓”、按你的节奏推送日报和异动提醒、只推和你持仓有关的公告新闻，还会建一个只有你能看的持仓看板。

> **一句话安装**（发给 Muse）：
> 请按 `{仓库地址}` 里 `v0.1.0` 版本的 `INSTALL.md` 安装，并先把要做的事列给我确认。

装完之后**不会再访问本仓库**；只有你说“更新”，它才会去检查新版本。

## 能做什么

| 你说 / 自动发生 | 结果 |
|---|---|
| “我的持仓”“总金额”“今天赚了多少” | 立刻回复持仓快照：总金额、今日盈亏、累计浮盈亏、每只明细、仓位 |
| “买了 100 股 NVDA 成本 180” | 记录持仓，可发“撤销”恢复 |
| “NVDA 跌破 150 提醒我” | 设置提醒 |
| 自动：异动提醒 | 日内涨跌幅超阈值、盘前盘后异动、触价、相对成本盈亏越线；分档、冷却，不刷屏 |
| 自动：日报 | 美股盘前/盘后、A 股和港股收盘 |
| 自动：持仓相关消息 | 只推和你持仓对得上的公告新闻，每条标明关联的是哪只、占多大仓位 |
| 美股夜盘 | 美东 20:00–04:00 的参考价（需自测通过后才开启，见下） |
| “XX 为什么涨/跌” | 查近 24 小时相关消息，查不到就如实说 |

推送去哪个渠道（App、微信、飞书、邮件）由你自己接好；本项目只产出内容，排版和发送由 Muse 按当前渠道处理。

## 它不做什么
- **不给买卖建议**，只陈述数据、事实和消息解读。
- **不碰你的账户**：不连券商，不下单，持仓是你自己告诉它的。
- 数据来自免费或非官方接口，**可能有延迟、可能随时失效**，仅供参考。

## 数据与隐私
- 持仓只保存在 Muse 云电脑的本地文件、你私有的 Space，以及你自己选的推送渠道里，不发给第三方。
- 唯一需要的账号是美股用的 Finnhub 免费 key（只有持有美股才需要），Muse 会帮你注册，验证码类步骤由你完成一次。
- 脚本只用 Python 标准库，**没有任何第三方依赖**，可以安装前自己先读一遍（`scripts/` 里 10 个文件）。

## 费用（token）
定时任务每次唤醒 Muse 是否消耗额度，取决于 Muse 的定时任务实现，**需要实测**。本项目已经把唤醒次数压到最低：只在开盘时段建任务、提醒速度分三档（1 / 5 / 15 分钟）、没事时立即结束。详见 [docs/COST.md](docs/COST.md)。

## 目录
```
INSTALL.md   给 Muse 看的安装说明（可重复执行）
USAGE.md     安装后 Muse 怎么响应你的话
scripts/     取数、计算、监测、日报、自测（纯标准库）
templates/   四个内容模板
cron/        定时任务清单
space/       持仓看板说明
docs/        数据源实测结论、费用说明
tests/       离线单元测试：python3 -m unittest discover -s tests
```

## 已知限制
美股夜盘、港股与 A 股盘中是否实时、港股公告、港股与 A 股新闻，目前都**没有验证过**，详见 [docs/data-sources.md](docs/data-sources.md)。没验证通过的功能会默认关闭，并如实告诉你。
